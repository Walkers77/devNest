
# DevNest - Web Development Learning Platform

## Project Overview
DevNest is a responsive educational website built
using HTML5 and CSS3.

This project was created for Week 01:
Web Foundations & Semantic HTML.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub

## Website Pages
1. Home Page
2. Programs Page
3. Task Detail Page
4. FAQ Page
5. Contact Page

## Features
- Semantic HTML5
- Responsive Design
- Accessible Navigation
- Contact Form
- FAQ Section
- Keyboard Accessibility

## How to Run
1. Download the project.
2. Open index.html in a browser.
3. Navigate using the menu.
