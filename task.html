WEEK 01

Web Foundations & Semantic HTML

Build a multi-page website using semantic HTML and accessible navigation.

Learning Objectives

  • Understand HTML document structure.
  • Use semantic HTML elements correctly.
  • Create accessible navigation links.
  • Build forms with proper labels.
  • Organize a project using Git.

Practical Tasks

  1. Create a Git repository.
  2. Create a README file.
  3. Add a GitHub issue template.
  4. Build five HTML pages.
  5. Use semantic HTML elements.
  6. Test keyboard accessibility.

Required Submission

  • GitHub repository link
  • Five completed HTML pages
  • Accessibility checklist
Acceptance Criteria: Pages must display correctly and the main navigation must work using a keyboard.
PRACTICE TASK

Build a Contact Form

Practice creating accessible forms using semantic HTML.

Requirements

  • Add a name field.
  • Add an email field.
  • Add a message field.
  • Connect labels with form inputs.
  • Add a submit button.
